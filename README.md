# Yandex Samokat — Web, Mobile & API Testing

Самостоятельный QA-проект по тестированию сервиса **Yandex Samokat**.

В рамках проекта проведено тестирование веб-приложения, мобильного Android-приложения для курьеров и REST API. Подготовлена тестовая документация, выполнены позитивные и негативные проверки, оформлены найденные дефекты.


Yandex Samokat — сервис для заказа самоката на определённую дату, время и адрес.

## Задачи тестирования

<details>
<summary><b>Web-приложение</b></summary>

1. Проанализировать требования к веб-приложению.
2. Составить чек-лист для функциональности экрана «Статус заказа».
3. Разработать проверки валидации полей экрана «Сделать заказ».
4. Провести тестирование функциональности веб-приложения по требованиям и макетам Figma.
5. Зафиксировать обнаруженные дефекты в виде баг-репортов.

Главная страница (лендинг) не входила в scope тестирования.
