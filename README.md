# Yandex Samokat — Web, Mobile & API Testing

Самостоятельный QA-проект по тестированию сервиса **Yandex Samokat**.

В рамках проекта проведено тестирование веб-приложения, мобильного Android-приложения для курьеров и REST API. Подготовлена тестовая документация, выполнены позитивные и негативные проверки, оформлены найденные дефекты.

## Что тестировалось

### Web

* функциональность веб-приложения;
* UI и соответствие требованиям;
* валидация полей и граничные значения;
* основные пользовательские сценарии;
* проверка в нескольких браузерах;
* сравнение интерфейса с макетами Figma.

### Mobile

* Android-приложение для курьеров;
* основные сценарии работы с заказами;
* отображение и обработка уведомлений;
* позитивные и негативные сценарии;
* тестирование на эмуляторе Android Studio.

### API

* REST API приложения;
* позитивные и негативные запросы;
* валидация параметров;
* проверка HTTP-кодов и тела ответа;
* граничные значения входных данных;
* проверка работы с данными через API.
